The problem

Lighting products are built from many components, and not every component works with every other one. Customers and specifiers needed a way to configure a product correctly, with the system managing which components are compatible and suggesting valid options, instead of checking spec sheets by hand.

What I did

  • Lead the project end to end: strategy, implementation, testing, delivery and post-release feedback analysis.
  • Built the product database in MySQL and the backend product API in Express.js.
  • Built the product and configuration management admin panel in Next.js.
  • Built a micro-parser that evaluates JavaScript-style rule expressions, used as logic gates for component-to-component compatibility checks and automatic suggestions of compatible options.
  • Wrote the chat API in FastAPI (Python) that connects the chatbot to the ML system. The ML team built the internal ML functionality with LangGraph and a vector database over the WordPress content.
  • Supported the React team in building the product configurator, with lumen output, performance and compatibility calculations, and integrating it into the WordPress site.
  • Oversaw the WordPress and ML teams.

Highlights

  • Covers 100 products across 15 product families and 150+ components.
  • Manages critical component combinations by component type and group, so customers can only configure valid products.

ProsperisGold

Group Thrift and Savings Platform

Type
Fintech platform for thrifting (rotating group savings, known in Nigeria as ajo or esusu)
Client
Nigeria-based company
Company
RS Software (2017 - 2019)
Role
Sole developer
  • PHP
  • CodeIgniter
  • MySQL
  • Paystack

The problem

In traditional thrifting, a group of people from a known circle each put in a fixed amount every month, and each cycle one member receives the whole pot. It runs on trust, cash and paper records. ProsperisGold moved it online so contributions, draws and payouts are tracked and paid automatically.

What I did

  • Designed and built the entire platform on my own in CodeIgniter and MySQL.
  • Built group thrifting, where members of a circle contribute monthly and a draw picks the member who receives each cycle's payout.
  • Built individual thrifting for personal savings goals, and enterprise thrifting for corporate partners and their staff.
  • Integrated Paystack, Nigeria's leading payment gateway, for monthly contributions and payouts.
